# FiscalIA

Proyecto Angular inicial para la Landing Page "FiscalIA".

- Desarrollador: IDS. Ociel Ortega Vazquez
- Unidad: UEPECV

Instrucciones rápidas:

1. Instalar dependencias:

```bash
npm install
```

2. Ejecutar en modo desarrollo:

```bash
npx ng serve --open
```

Notas: Este repositorio incluye los estilos base replicados desde el proyecto `RedesSociales-main`.

Assets:
- Coloca imágenes reales en `src/assets/img/` (nombres esperados: `facebook.png`, `instagram.png`, `web.png`, `whatsapp.png`, `youtube.png`, `messenger.png`, `telegram.png`, `tiktok.png`, `LogoAzulG.png`, `background.png`).
