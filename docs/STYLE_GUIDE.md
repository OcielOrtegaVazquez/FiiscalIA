# Style Guide

- **Nombre del proyecto:** FiscalIA
- **Tipografía:** Inter (importada desde Google Fonts)
- **Paleta:**
  - Primario: #0D47A1 — Azul institucional
  - Secundario: #1976D2
  - Fondo: degradado azul oscuro

- **Componentes importantes:**
  - `Navbar` — menú circular animado (reposicionado top-left en móvil)
  - `Hero` — título grande, logo y CTA principal

- **Responsive:** diseño mobile-first; usar `clamp()` para tipografías y media queries en 600px/1024px.
